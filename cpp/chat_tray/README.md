# OTD421 Chat Tray

Небольшой Windows-клиент на C++, который:

- висит в системном трее
- логинится в `otd421`
- опрашивает чат
- показывает уведомление и компактное окно ответа
- умеет отвечать в личный или общий чат

## Что нужно на сервере

Нужен маршрут:

- `/login`
- `/api/chat/send`
- `/api/chat/tray/incoming`

Последний уже добавлен в текущий проект.

## Сборка через CMake

```powershell
cd C:\project\otd421\cpp\chat_tray
cmake -S . -B build
cmake --build build --config Release
```

Готовый `.exe` будет в:

```text
cpp/chat_tray/build/Release/otd421_chat_tray.exe
```

## Конфиг

Скопируйте `config.ini.example` рядом с `.exe` как `config.ini` и заполните:

- `base_url`
- `username`
- `password`
- `poll_seconds` по умолчанию 30 секунд
- `ignore_ssl_errors=1` для self-signed сертификата

## Поведение

- личные сообщения открывают быстрый ответ конкретному отправителю
- сообщения в общий чат открывают быстрый ответ в общий чат
- по двойному клику на иконку можно открыть окно ответа
- через меню трея можно открыть веб-чат, переподключиться или выйти

## Ограничение

Прямой inline-reply внутри нативного Windows toast без отдельной WinRT-обвязки здесь не реализован.  
Вместо этого программа показывает компактное окно ответа возле трея, что надёжнее и проще в сопровождении.
