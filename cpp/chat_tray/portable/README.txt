OTD421 Chat Tray Portable

Состав:
- otd421_chat_tray.exe
- start_chat_tray.bat

Как использовать:
1. Скопируйте всю эту папку на другой компьютер.
2. Запустите start_chat_tray.bat или otd421_chat_tray.exe.
3. В окне настроек укажите адрес сервера, если он отличается.
4. После подключения выберите себя из списка и введите пароль.

Особенности:
- настройки хранятся рядом с программой
- проверка новых сообщений выполняется примерно раз в 30 секунд
- дополнительный Visual C++ Redistributable обычно не нужен, потому что runtime встроен в exe

Требования:
- Windows 10/11 x64
- доступ к серверу OTD421 по сети
